# ROADMAP

Langzeitprojekt, kein Saisonbetrieb. Keine Countdowns, keine Battle-Pässe, keine künstliche Eile.
Jede Phase ist abgeschlossen, wenn sie sich im Spiel richtig anfühlt — nicht wenn sie fertig aussieht.

---

## Phase 0 — Fundament ✅

- [x] Begehbare Welt mit Kollision und Pointer Lock
- [x] Vier Räume, 38 Exponate, zwei Terminals
- [x] Punkte, Ränge, Tagesaufträge
- [x] Lokale Speicherung, kein Konto
- [x] 20 Tests für Logik und Kurator

## Phase 1 — Bildsprache ✅

- [x] Dithering-Shader mit fünf Farbstufen
- [x] 1-Bit-Oberfläche: HUD, Menü, Panels, Formulare
- [x] Zielrahmen mit Beschriftung statt Fadenkreuz
- [x] Neuer Avatar: Mantel aus Punktmatrix-Stoff, Bildschirmkopf, Stempel
- [x] Menü mit Bestand, Protokoll, Über, Anonymität, Konto

## Phase 2 — Klang

- [ ] Schritte auf Stein, Holz und Teppich (prozedural, WebAudio)
- [ ] Hallfahne je Raum — die Halle klingt anders als die Bibliothek
- [ ] Klicken und Summen der Terminals
- [ ] Stempelaufschlag, wenn der Kurator urteilt
- [ ] Sehr leiser Grundton, der in der Bibliothek wärmer wird
- [ ] Stummschalter im Menü

## Phase 3 — Inhalt

- [ ] Depot: abgelehnte Vorschläge bleiben einsehbar
- [ ] Zeitstrahl im Foyer, 1983 bis heute
- [ ] Themenausstellung pro Monat, vom Kurator kuratiert
- [ ] 20 weitere Exponate, Schwerpunkt 2010er
- [ ] Ein zweiter Raum für Vorläufer (BTX, MausNet, Mailboxen)
- [ ] Gästebuch, das wirklich speichert

## Phase 4 — Der Kurator wird echt

- [x] Gesprächsfenster mit Absichten und echtem Spielstand
- [x] Eigene Funde: er sucht selbst und legt sie dem Gremium vor
- [x] Gedanken im HUD, Status je Tätigkeit
- [ ] `judge()` an ein Sprachmodell anbinden (Edge Function)
- [ ] Urteile mit Begründung in seiner eigenen Stimme
- [ ] Freie Fragen im Gespräch, nicht nur erkannte Absichten
- [ ] Ein Gedächtnis: was er dir gestern gesagt hat

## Phase 5 — Gemeinsames Gremium

- [ ] Abstimmungen über einen Server, damit Stimmen von anderen kommen
- [ ] Anonyme Kennung ohne E-Mail
- [ ] Monatliche Auszählung statt Dauerabstimmung
- [ ] Anzeige, wer gerade im Haus ist (ohne Namen)

## Phase 6 — Kleine Spiele

- [ ] Moorhuhn-Jagd am Automaten, im 1-Bit-Look
- [ ] Ein Textadventure in der Bibliothek
- [ ] Highscores auf einer Kreidetafel

---

## Prinzipien

1. **Kein Zeitdruck.** Wer zwei Wochen nicht da ist, verliert nichts.
2. **Kein Grind.** Punkte kommen aus Neugier, nicht aus Wiederholung.
3. **Keine Werbung, kein Tracking, kein Konto.**
4. **Jede Behauptung im Spiel ist belegbar** — oder als unsicher markiert.
5. **Der Kurator widerspricht auch mal.** Eine KI ohne Meinung ist ein Formular.
6. **Die Sprache schließt niemanden aus.** Kein Gendern, keine Anreden, die Leute aussortieren.
